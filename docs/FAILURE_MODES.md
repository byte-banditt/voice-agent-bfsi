## Follow-up verification (local changes in this worktree)

| Prior issue | Current disposition | Evidence / remaining limit |
|---|---|---|
| `malformed_tool_arguments` allowed plausible model-guessed identity fields | Fixed at conversation boundary: model DOB and phone suffix must be present in the current caller utterance before `BFSIToolExecutor` runs. Shape validation still rejects malformed input. | `tests/test_conversation.py::test_plausible_but_invented_identity_values_never_reach_executor`; synthetic scenario JSON. This cannot prove ASR transcript correctness. |
| `grounding_violation` test required an event even when model safely refused | Evaluator now passes when unsupported values are absent and either the deterministic guard intervened or the model safely refused. A guard event is not treated as proof that unsafe speech escaped. | `tools/evaluate_scenarios.py`; `docs/TEST_PLAN.md`. Guard event means the server replaced unsupported output before TTS. |
| Natural spoken DOB required unnatural synthetic ISO pronunciation | Server normalizes unambiguous ISO or English month/day/year to CRM ISO form; invalid/ambiguous slash formats fail closed. | `app/tools.py::_normalize_dob`, `tests/test_tools.py::test_spoken_english_date_of_birth_normalizes_to_crm_format`. Locale ambiguity from ASR still requires caller clarification. |
| 3/30 audio turns omitted loan-status lookup | Status intent is retained in the conversation engine; after verification, server performs a scoped first-fixture-loan lookup even when model omits it. It does not implement a business “active loan” rule. | `tests/test_conversation.py::test_server_requires_status_lookup_when_verified_caller_asks`, `tests/test_crm.py`; fake and local model scenario artifacts. The old 30-turn artifact is historical and not rerun by this change. |
| Stored traces could contain sensitive tool arguments and loan result payloads | Persisted traces now store argument field names only and replace account-specific tool result data with redacted success/failure summaries. | `tests/test_observability.py`; no audio is persisted. Existing local databases are not retroactively scrubbed. |
| Human tool could fail while agent claimed transfer succeeded | Conversation path now gives an explicit failure response and guardrail event if transfer backend returns an error. | `tests/test_conversation.py::test_failed_human_transfer_is_not_reported_as_success`. |
| Browser consent/microphone sequence | Protocol simulator evaluation now ignores ephemeral transcript messages and checks the subsequent audio/clear ordering. Client suppresses microphone capture during playback. | Physical browser/device test remains **OPEN**; route and simulator evidence are not hardware evidence. |
| Phone suffix could be borrowed from a nearby DOB; negated callback/payment-link intent could trigger writes; failed status lookups could retry on unrelated turns | Fixed grounding to require phone digits adjacent to explicit phone/last-four labels; refusal/negation disables corresponding tool intent; status failure clears pending intent until a fresh caller request. | `tests/test_conversation.py::test_phone_suffix_cannot_be_inferred_from_a_nearby_dob`, `test_negated_callback_and_payment_link_requests_do_not_execute`, `test_failed_status_lookup_does_not_retry_on_later_unrelated_turn`. |
| Local loan route implied a business “active loan” rule while returning the first ID-sorted fixture | Renamed route to `/customers/{customer_id}/loans/first` and documented that production eligibility must come from client CRM policy. | `tests/test_crm.py`; `docs/INTEGRATION_CONTRACT.md`. |
